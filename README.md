## Contributing

`main` is protected. Direct pushes are blocked.

1. Create a branch from `main` (e.g. `bugfix`, `tests`).
2. Push it and open a pull request into `main`.
3. Get 1 approval from a teammate (you can't approve your own PR).
4. Merge using **Create a merge commit** (not squash) so history stays visible in `git log --graph`.
